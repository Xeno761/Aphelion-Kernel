# Aphelion — known-unresolved vendor module symbols.
#
# The pre-flight audit cross-checks every undefined symbol in every vendor
# module it can see against this kernel's exports (vmlinux + the other vendor
# modules). Anything listed here is EXPECTED to be unresolved; anything new is
# fatal.
#
# The audited set now covers all three module locations on the device:
#   rev/vb/rd/lib/modules       223  from vendor_boot ramdisk
#   rev/dlkm/lib/modules        310  from vendor_dlkm
#   rev/system_dlkm/lib/modules  60  GKI set, pulled from the running device
#
# Pulling system_dlkm removed the 14 false gaps that used to sit here: arc4_*,
# hci_* and rfkill_* resolve from bluetooth.ko / rfkill.ko in that partition.
# Nothing below is a GKI provider any more.
#
# None of the remaining 52 is caused by a config choice in this tree: the code
# is not exported anywhere in this source tree, so no defconfig edit can create
# or remove them. They belong to Oplus and Lenovo components whose provider
# modules are not in any image we have.
#
#   1. Oplus scheduler extensions (scx / hmbird):
#
#      __scx_ops_enabled, scx_*, task_is_scx, hmbird_dir, iso_masks,
#      __tracepoint_android_*_scx_*, __tracepoint_android_*_hmbird_*,
#      __traceiter_android_vh_scx_update_task_scale_time
#
#   2. Oplus display / touch / sensor bus hooks:
#
#      register_lcdinfo_notifier, unregister_lcdinfo_notifier,
#      touchpanel_event_*, tp_judge_ic_match, tp_util_get_vendor,
#      magcvr_*, olc_raise_exception, oplus_kevent_fb,
#      oplus_mrdump_mini_add_misc, oplus_read_mm_config,
#      get_support_sensor_list, get_pogo_keyboard_operations
#
#   3. Lenovo / MTK bootloader and helpers from source this tree lacks:
#
#      get_boot_mode, get_eng_version, get_PCB_Version, verified_bootstate,
#      is_confidential, register_devinfo, request_firmware_select,
#      ext_module_loaded, fb_kevent_send_to_user, get_mem_cgroup_app_name,
#      get_mem_cgroup_app_uid, get_next_memcg, get_next_memcg_break,
#      get_slabinfo, osvelte_kallsyms_lookup_name,
#      __tracepoint_android_vh_get_util,
#      __tracepoint_android_vh_init_adjust_zone_wmark,
#      __tracepoint_android_vh_throttle_direct_reclaim_bypass,
#      __tracepoint_android_vh_tick_nohz_idle_stop_tick
#
# These belong to modules that do not load on this device, which is why the
# kernel boots without them. Prune entries as they get fixed.
